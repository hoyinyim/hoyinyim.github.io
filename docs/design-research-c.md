# 設計研究附錄 C｜藝術展示與沉浸式敘事

查閱日期：2026-11-20。獎名及日期以 CSS Design Awards（CSSDA）作品頁原標題為準；Special Kudos 為評審肯定，不寫成 Website Of The Day。實際頁面以 Chromium 桌機 1440 × 900 與觸控型 390 × 844 CSS px 模擬檢查，非實體手機驗收。讀取頁面可見情境、DOM 與樣式，抽查滾輪／觸控、可見控制和站內入口；不以單張畫面判斷動畫，不引用或移植第三方程式與素材。

- **【實測】** 當次載入畫面或實際操作結果。**【原始碼／DOM】** 公開文件、資產路徑或瀏覽器屬性可重查的技術證據。
- **【官方】** 獎方或製作方資料；獎方標籤不等於函式庫或演算法已證實。**【推測】** 僅說明可能性。**【延伸】** 本學術站自己的構想。

## 11. ris. ArtWork

- **名稱、網址、作者、獎項（【官方】）**：[ris. ArtWork 原網址](https://www.ris-artwork.com/)，CSSDA 登載作者 ris.（日本），[2024-01-24 Special Kudos](https://www.cssdesignawards.com/sites/ris-artwork/44985/)，標示 animated、minimal、WebGL。
- **首頁構成、色字網格與留白（【官方存檔圖】，非現行網站）**：深炭黑大底，中段偏中央為獨立窄幅作品；左側襯線題名、右側日期、上角窄導覽與下方 Prev／View／Next 不搶視線。條紋與一點朱紅引導視線，四周留空。字體名稱、手機網格均不可由圖反推。
- **滑鼠、捲動、轉場、圖文動態及桌機／手機（【未完成實際互動驗證】）**：原網址桌機和手機瀏覽均回傳 404／DEPLOYMENT_NOT_FOUND，另核對不帶 www 的根網址亦為 404；未能核查截圖中按鍵、百分比、作品移動、頁面轉場或窄版重排。畫面所呈現只是「作品為主、題名與控制為副」的靜態位置。
- **技術**：WebGL 只屬【官方】獎方標籤；當前無法驗證原頁的 WebGL 程式或 Canvas，不能根據模糊平面推定位移 shader。
- **可取／不取（【延伸】）**：給既有墨畫足夠留白，題名與出處鄰接但低於圖像層級。保留能用鍵盤操作的前後翻頁；不採無標示百分比、低對比或以動效為唯一入口。

## 12. MILEZ

- **名稱、網址、作者、獎項（【官方】）**：[MILEZ](https://milez.jp/)，獎方主體為 MILEZ，協作者 Taisei Dofuku、ITEM；[CSSDA 2026-01-23 Website Of The Day](https://www.cssdesignawards.com/sites/milez/48734/)。官方站說明為記錄日本文化、傳統與工藝的企劃；獎方標籤為 liquid、video/sound 與 WebGL。
- **首頁視覺、色字／網格（【實測】）**：黑底、上方置中小字標，聲音 On／Sound／Off 分列；極細垂線和弧線維繫空間，窄身高反差襯線聲音提示對比於小型無襯線字標。選 Off 後大幅暗灰形態漸次浮出，隨後成為作品導覽：上方短文、居中黑白手藝影像、下方日文題名與年代，底層是略有顏色的全幅紋理，點線連到相鄰項。主圖桌機約畫幅三分之一、390 px 約八成寬；手機沿用固定舞台，左右相鄰項裁切較多。執行期載入多種字體，含 DNP 秀英明朝系列與 tt-ricks、Inter。
- **滑鼠、捲動、轉場（【實測＋範圍限制】）**：桌機點選 Off，手機觸控 Off，均在原網址從聲音提示進入黑色開場。穩定後桌機滾輪使貴船神社換為千鳥酢，中間影像、題名、連結和背景同時換項，文件 `scrollY` 仍為 0；這能確認案例切換，不能說動畫進度與滾輪逐像素連續對應。手機早期滑動未能排除開場本身的運動。主畫面中央的滑鼠移動未單獨隔離出游標跟隨。桌機實際用 Menu → Archive 開啟 `/archive/`，不推定該跨頁效果的特定函式庫或時值。
- **圖、字、動畫（【實測】）**：Off 拿掉聲音抉擇的字列，輪廓與紋理承接第一幕；案例切換時，以同一日文題名、年代、短文與影像共同標識作品。頁面也提供 Archive／Philosophy 等明文路徑。
- **技術（【原始碼／DOM＋執行期】）**：公開資產含 `/_next/static/`；初始 DOM 有兩塊 canvas。桌機與手機模擬於導入成功後，均觀察到原頁成功取得 `2d` 與 `webgl2` context（監測呼叫後交回原生結果）；與獎方 WebGL 標籤可相互印證，仍未映射全部圖層或推定 Three.js、shader 公式、媒體解碼路徑。
- **可取／不取（【延伸】）**：以圖像和題文共同指向同一章節，畫卷當作附加展示，備有直接開啟書目或全文的路徑。捨棄資料首頁的入場選擇門檻、液態全螢幕和非原生捲動；這類效果在長文容易妨礙定位、回讀與動作敏感者。

## 13. THE TAWARAYA

- **名稱、網址、作者、獎項（【官方】）**：[俵屋旅館／THE TAWARAYA](https://the-tawaraya.jp/)，[CSSDA 2026-04-05 Special Kudos](https://www.cssdesignawards.com/sites/the-tawaraya/49158/) 登載 STARRYWORKS inc.；[製作說明](https://www.starryworks.co.jp/works/tawaraya) 署名 RASTAHOUSE、STARRYWORKS inc.，導演／設計名單見原頁。製作方說明跨 12 個月拍攝，各月片段隨造訪選播；本次只於當月抽查，不由兩個樣本推廣至所有月份。
- **首頁視覺、色字／網格（【實測】）**：入場先黑底中央白色印記，進入後影片形成水平寬景，帶黑邊與大面積暗部。桌機英字導覽在左、日文縱排在右，居中區交給器物或環境，不把所有資訊壓在同一中央欄。宣告及載入字體含筑紫 C 老明朝、Univers Light；兩者各司日文縱書和英字。
- **滑鼠、捲動、轉場（【實測】）**：滑入 ABOUT 的抽樣未見大幅尺度變化。桌機滾輪使畫面進入白地，影片縮進頁緣，月名／題名及段落另行出現；DOM 捕捉到文字 `opacity`、`transform` 與字距動畫。點 ABOUT 已到 `/about`，未把未量得的跨頁運動寫成固定疊化。手機以指令滾至相應進度觀察重排，非實體滑動順暢度測試。
- **圖、字、動畫與窄版（【實測】）**：桌機觀察到寬景，手機改為近方形的影片窗口、底部圖示控制，窄版圖→短縱書題→正文依序排開；月名與鏡頭建立場景關係，正文另有白底。當次兩尺寸抽樣的影片 `currentTime` 有增加，且 `muted=true`，不主張其所有訪客的音訊預設。
- **技術（【原始碼／DOM】）**：`/_next/static/` 資產、實際 `video` 元素、日文導覽的 `writing-mode: vertical-rl`；沒有 Canvas 的 DOM 證據，不歸為 WebGL。框景與文字運動可參考【推測】以一般 CSS 轉場加區塊觸發重作，非原站實作斷言。
- **可取／不取（【延伸】）**：學術頁用一張本站水墨圖、短題識與獨立正文接續；僅短題識採縱書，手機可還原橫書。別以六秒級載入開場、全頁影片或難點小圖示作為進入文章的必要步驟。

## 14. Tamaki Yoshida — Portfolio

- **名稱、網址、作者、獎項（【官方】）**：[𠮷田多麻希作品集](https://www.tamakiyoshida.com/)，由 D2C Inc. 規劃 VI 與作品網站，[官方製作及完整分工](https://www.d2cid.co.jp/projects/tamaki_yoshida/)；[CSSDA 2026-06-05 Special Kudos](https://www.cssdesignawards.com/sites/tamaki-yoshida/49502/)。
- **首頁視覺、色字／網格（【實測】）**：淺灰近白的首屏、近全幅黑色襯線字標在下緣，一小段創作說明與極簡導覽成為讀者錨點。首屏不塞作品縮圖；作品區將大空白改為等欄槽、上下自然高度的攝影。格中有題名、作品類型、年份；字標本身為圖檔，頁面群組有 EB Garamond、日文題名 `YakuHanMPs`／Shippori Mincho 字體堆疊。
- **滑鼠、捲動、頁面轉場（【實測】）**：原生滾輪確實推進桌機文件；作品首圖 hover 前後讀到的 `opacity`、`transform` 與 `filter` 相同，無證據稱它有圖像變形。桌機和手機均從首頁點入[同一作品明細](https://www.tamakiyoshida.com/works/4pss0_ykjg)，桌機於操作後擷取到約 800 ms 的 opacity／visibility 轉場，手機未量出同樣幀序，不推廣成兩者完全等同。
- **圖、字、動畫與差異（【實測】）**：桌機字標單行、左側篩選與右側三欄；390 px 字標自然拆為兩行、導覽收納到按鈕、作品為兩欄，Filter 位於列表之前。保持各圖片的長寬及其下的題名，不以同尺寸圖塊裁掉重要細節。
- **技術（【原始碼／DOM】）**：本次讀到 Next 路徑、原生圖像、URL 層級和表單篩選控制，首頁未見 Canvas；不把淡出歸因於 WebGL。
- **可取／不取（【延伸】）**：作品縮圖＋題名＋資料來源為一個完整單元，先有語意明確的年份／類型控制，再使用局部動效。首屏大字標與整屏空白只作展示參考，學術身分及入口需於首屏有實際可讀位置。

## 15. 45R Denim Karuta

- **名稱、網址、作者、獎項（【官方】）**：[デニムかるた｜45R](https://45r.jp/ja/45denim-karuta/)，[CSSDA 2025-03-10 Website Of The Day](https://www.cssdesignawards.com/sites/45r-denim-karuta/47168/)，SHIFTBRAIN Inc. 與 ingraft inc.、COPILOT Inc.、Keiji Yano、haon, inc. 合作。[製作方專案頁](https://shiftbrain.com/work/45rpmstudio-denimkaruta/?lang=en) 交代原創插畫、音效與手機優先，另列 FWA／Awwwards 的當日獎；[品牌公告](https://45r.jp/ja/news/denimkaruta_release/) 說明 45 枚卡及遊戲／知識雙用途。
- **首頁視覺、色字／網格（【實測】）**：先在近白紙面置中展示奶油色札圖，後有海軍藍字、暖棕圓角操作和插畫；練習題轉用靛布質地、奶油色大字、白色短說明泡。DOM 標題為 A1 Gothic B，實測桌面約 48 px、手機約 30 px。圖主角與字稿同為問題的線索。
- **滑鼠、捲動、轉場（【實測＋限制】）**：在桌機 hover 開始控制未分離出可單獨重現的大動作。初始頁滾輪未位移整份文件；桌機點開始、手機點開始都在同一網址切到練習場景，擷取到逐字 `transform`／`opacity`。遊戲介面另列拖曳找圖、圖鑑與聲音選擇，未完成全部拖曳、答題、圖鑑及音訊播放驗證。
- **圖、字、動畫與窄版（【實測】）**：桌機練習題一行，390 px 允許拆成兩行，控制移到上下堆疊，不把寬桌面整張縮小；圖案與說明依使用者進入的同一題配對。
- **技術（【原始碼／DOM】）**：公開載入 `_astro` 資產，實際 DOM 有 SVG、Canvas、按鈕及文字，動畫可讀到元素 transform／opacity；不由一塊 Canvas 或獎方 multimedia 標籤指定 Three.js 或 Canvas 當作核心渲染路徑。
- **可取／不取（【延伸】）**：古文字／研究主題札可點開對應原圖與題文；同時保留原始漢字、直達章節、鍵盤控制與關閉返回。去掉闖關、計分、計時、入場音效和必須拖曳才能讀材料的條件。
